<CourseNote kind="algebra" title="Why is x = (x + 4) − 4 allowed?">
Adding 4 and then subtracting 4 adds zero, so $x = (x+4) - 4$ is true for **every** number $x$. That makes it a purely algebraic step (`ring`), and it doesn't use the fact $x + 4 = 2$ at all.

The trick is choosing which zero to add. We add $4 - 4$ because it makes $x + 4$, the left-hand side of our fact, appear inside the expression. Then we can substitute.
</CourseNote>

<CourseNote kind="guide" title="Same moves as Algebra I, written as one chain">
In Algebra I you solved $2x + 3 = x$ by changing **both sides** of the equation, line after line. The chain above does the same arithmetic, but every line stays a statement about $x$ itself, so the whole thing reads as one proof: $x = \ldots = -3$. Lean only accepts this second style, which is why the book trains it.
</CourseNote>

<Book file={CH1} section="tips-and-tricks" parts={["id27", "id28"]} />

<CourseNote kind="algebra" title="How do you find the right combination?">
To get $x$ from $x + y = 4$ and $5x - 3y = 4$, you need multiples of the two equations whose $y$'s cancel: $3(x + y) + 1(5x - 3y) = 8x$. So $x = \frac{3(x+y) + (5x-3y)}{8}$.

On scratch paper, ask: **"What do I multiply each fact by so the variable I don't want disappears?"** Then divide by whatever is left in front of $x$.
</CourseNote>
